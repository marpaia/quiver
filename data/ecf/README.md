# ECF sigma-factor activator corpus

Characterized **activator** components, the counterpart to Cello's repressor-only gates. Extracytoplasmic
function (ECF) sigma factors activate their cognate promoters, so each row here becomes an `activator`
Component (`role="activator"`), grounding a `hill1` stage with `alpha = [ymin, ymax]` (output high when the
sigma factor is high). An activator lets a design turn a promoter on rather than only off, instead of
forming repressor chains only.

`ecf_activators.csv` holds **32 functional ECF sigma-factor activators** (on-target fold induction >= 5),
generated by `ingest_ecf.py` from the Rhodius et al. 2013 supplement. It is reference data in the same flat
schema `quiver.parts` reads, so a library is loaded from it directly:

```python
ecf = quiver.parts("data/ecf/ecf_activators.csv", strain=Strain("E. coli"), provenance=Provenance.LITERATURE)
```

`quiver.component.load_ecf()` and `quiver.component.load_flat_csv` remain for inspecting the corpus as a
bare `ComponentLibrary`; both return an **empty library if the file is absent**, so an unpopulated corpus is
a no-op rather than an error.

**This corpus cannot be combined with Cello's.** `quiver.combine` refuses libraries measured under
different conditions, and that refusal is correct here: these rows report only a fold induction, so their
absolute levels are a nominal placeholder (see the loader's nominal-OFF convention below) and are not on
Cello's RPU scale. Only the dynamic range is a measurement. Composing the two would be arithmetic across
incommensurable scales.

## Schema (`ecf_activators.csv`)

One row per characterized sigma:promoter switch. Columns:

| column | required | meaning |
| --- | --- | --- |
| `name` | yes | display/part name carried into LOICA/SBOL export |
| `regulator` | no (defaults to `name`) | the sigma factor — the **orthogonality key** (no regulator twice in one circuit) |
| `role` | no (defaults to `activator`) | `activator` / `repressor` / `sensor` |
| `ymax`, `ymin` | either this pair… | ON and OFF expression levels (RPU) |
| `dynamic_range` | …or this | fold activation; when given without `ymax`/`ymin`, `ymin` is set to a nominal OFF level and `ymax = ymin * dynamic_range` |
| `K`, `n` | no | Hill half-max and cooperativity; default when absent |
| `family`, `organism` | no | metadata |
| `quality` | no (defaults to `literature`) | `measured` / `fitted` / `literature` |
| `source` | no | citation/accession, recorded in provenance |

Only the **dynamic range** is treated as a reliable cross-corpus quantity (matching quiver's realizable clamp,
which trusts dimensionless quantities only); absolute levels derived from a fold-change are nominal, which is
why fold-change-only rows are tagged `quality="literature"`.

## Provenance

The shipped `ecf_activators.csv` is derived from **Rhodius et al. 2013**, *Design of orthogonal genetic
switches based on a crosstalk map of σs, anti-σs, and promoters*, Molecular Systems Biology 9:702,
doi:[10.1038/msb.2013.58](https://doi.org/10.1038/msb.2013.58), **CC BY**. Each ECF sigma factor's on-target
average fold induction (supplementary dataset `msb201358-s3.xlsx`, sheet "S2.1 - Sigma orthogonality", paired
to its cognate promoter by ECF group) is the activation dynamic range; only functional switches (fold >= 5)
are kept. Only the dynamic range is a measured quantity used here; absolute expression levels follow the
loader's nominal-OFF convention, hence `quality="literature"`.

## Regenerating

`ingest_ecf.py` parses the supplement deterministically. Fetch it (no login) from EuropePMC and run:

```bash
curl -L -o supp.zip https://www.ebi.ac.uk/europepmc/webservices/rest/PMC3817407/supplementaryFiles
unzip supp.zip -d supp
uv run --with openpyxl python ingest_ecf.py supp   # rewrites ecf_activators.csv
```

`openpyxl` is needed only to regenerate (the shipped loader reads the CSV and needs no xlsx parser). To add
more corpora, drop another CSV in `data/<corpus>/` and load it with `quiver.parts(path, strain=...)`.

Other characterized activator sources that fit the same schema: **Bervoets et al. 2018** (*A sigma factor
toolbox for orthogonal gene expression in E. coli*, Nucleic Acids Research) and **Van Brempt et al. 2020**
(*Predictive design of sigma factor-specific promoters*, Nature Communications, PMC7670410).
